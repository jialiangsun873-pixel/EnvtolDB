EnvTolDB（环境耐受蛋白数据库）收录 5 个环境组、231 个物种、668888 条 UniProt 蛋白序列本体与 539,714 条实验测量（ddG/ΔTm/Tm vs pH/溶剂 Tm）。每条序列带 accession（可点开 uniprot.org 核对）与 sha256 校验和；浏览对全站登录用户开放；数据修订仅限管理员，每次写入都记录操作人。

如何使用本站

① 按物种浏览：每个物种页列出全部入库蛋白（含 pLDDT/盐桥）与 FASTA 下载； ② 溶剂统计：17 种有机溶剂的 ΔTm 聚合； ③ 下载：整库 SQLite、每池 TSV、每物种 FASTA； ④ 批量/程序化访问请下载 SQLite 后本地 SQL 查询（schema 见 API 文档页）。

核验声明

每条序列可通过 accession 在 uniprot.org 打开官方条目比对；SHA-256 用于完整性校验； 人工核验记录（verified）必须附带核验证据；所有导入批次记录来源声明与时间。
