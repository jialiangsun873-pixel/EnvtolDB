API（自托管实例）

完整 REST API 随自托管实例提供（登录后 /dataset/api 查看）。 本 GitHub Pages 镜像为静态只读版：提供浏览、聚合与下载；程序化检索请下载数据文件本地查询。

本地查询示例（下载 SQLite 后）

sqlite3 dataset.db "SELECT kind, COUNT(*) FROM experiments GROUP BY kind"
sqlite3 dataset.db "SELECT accession, mean_plddt, salt_bridges_per_100 FROM structures
                    WHERE salt_bridges_per_100 > 6 ORDER BY 3 DESC LIMIT 20"

数据字典

字段说明
pool环境组，取值见上方各池（thermo/salt/ph/solvent/meso）
grade组内分级：salt=extreme|moderate；ph=acidophilic|alkaliphilic；其余见 pools 配置
lit_anchoredEurope PMC 严格共现检索（物种名 × 环境词，标题/摘要）是否命中
evidence_level溶剂组人工评级：high / medium / medium-strain-unverified / weak / hydrocarbon-only
bacdive_valueBacDive 实测最优生长条件：salinity 单位 M NaCl；ph_opt 单位 pH
proteins.seq_sha256序列 SHA-256；任何拷贝都可校验完整性
proteins.verified人工核验标记；核验时必须写 evidence（做了什么比对）
attrs自定义参数 JSON，key 受字段定义约束（类型/枚举校验）
